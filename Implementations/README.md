# WeaverKEM Implementations

## Directory Structure

```
Implementations/
├── Reference_Implementation/
│   ├── WeaverKEM-128/   # 128-bit classical / 80-bit quantum security
│   ├── WeaverKEM-256/   # 256-bit classical / 128-bit quantum security
│   └── WeaverKEM-512/   # 512-bit classical / 256-bit quantum security
├── Optimized_Implementation/
│   ├── WeaverKEM-128/   # AVX2-optimized, 128-bit classical security
│   ├── WeaverKEM-256/   # AVX2-optimized, 256-bit classical security
│   └── WeaverKEM-512/   # AVX2-optimized, 512-bit classical security
Test_Vectors/            # KAT output files (generated by build)
```

## File Descriptions

### Files that SHALL NOT be modified (provided by ICCS)

| File | Description |
|------|-------------|
| `drng.c` | Source file of Deterministic Random Number Generator (SM3-DRNG) |
| `drng.h` | Header file of Deterministic Random Number Generator |
| `auxfunc.c` | Source file of auxiliary functions (SM3, pseudoHash, pseudoXOF) |
| `auxfunc.h` | Header file of auxiliary functions |
| `KAT_KEM.c` | Source file for generating KEM test vector files |

### Files that implement the algorithm (WeaverKEM-specific)

| File | Description |
|------|-------------|
| `KEM_WeaverKEM-XXX.h` | Programming interface header; sets `ALGORITHM_INSTANCE` and `OUTPUT_BLANK_TEST_VECTORS` |
| `KEM_WeaverKEM-XXX.c` | Interface implementation; bridges WeaverKEM core to ICCS API; redirects randomness to SM3-DRNG |
| `KEM_AlgorithmInstance.h` | Thin include shim only (official `KAT_KEM.c` includes this filename) |
| `symmetric.h` / `symmetric-iccs.c` | ICCS hash/XOF layer (`auxfunc`); shadows `ref/src/symmetric.h` at build time |
| `CMakeLists.txt` | Automated build script; also drives KAT generation |

## Algorithm Parameter Sets

| Instance | WEAVER_MODE | Classical Security | Quantum Security | PK (bytes) | SK (bytes) | CT (bytes) | SS (bytes) |
|----------|-------------|-------------------|-----------------|------------|------------|------------|------------|
| WeaverKEM-128 | 1 | 128-bit | >=80-bit | 608 | 1440 | 704 | 16 |
| WeaverKEM-256 | 3 | 256-bit | >=128-bit | 1312 | 2912 | 1408 | 32 |
| WeaverKEM-512 | 5 | 512-bit | >=256-bit | 2592 | 5728 | 2944 | 64 |

*Note: Exact sizes are determined at compile time by `params.h` based on `WEAVER_MODE`.*

## Design Notes

### Randomness
All randomness in the KEM operations is sourced from the ICCS-provided SM3-DRNG
(`drng_algorithm`). The `randombytes()` function in `KEM_WeaverKEM-XXX.c` is
overridden to call `get_random_number(&drng_algorithm, ...)`, ensuring that
test-vector generation is fully deterministic and reproducible.

### Hash Functions
Each instance directory contains `symmetric.h` and `symmetric-iccs.c` (ICCS
hash/XOF via `auxfunc`). Build uses `-include symmetric.h` so `ref/src` sources
use `sm3hash` / `pseudohash` / `pseudoXOF` without modifying `ref/src`.
`KAT_KEM.c` and `auxfunc.c` are unmodified copies from API_PKC.
