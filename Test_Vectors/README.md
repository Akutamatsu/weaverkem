# Test_Vectors

This directory contains Known Answer Test (KAT) vector files for all WeaverKEM
algorithm instances. These files are generated by compiling and running the
KAT_KEM program in each instance directory under Implementations/.

## Files

| File | Algorithm Instance | Security Level |
|------|--------------------|----------------|
| KAT_KEM_WeaverKEM-128.txt | WeaverKEM-128 | 128-bit classical / 80-bit quantum |
| KAT_KEM_WeaverKEM-256.txt | WeaverKEM-256 | 256-bit classical / 128-bit quantum |
| KAT_KEM_WeaverKEM-512.txt | WeaverKEM-512 | 512-bit classical / 256-bit quantum |

## File Format

Each file contains 10 test cases. Each test case has the following fields:

```
Count = <integer>          # Test case index (0-9)
Seed_Len = 64              # Seed length in bytes
Seed = <hex>               # 64-byte DRNG seed (generated by ICCS SM3-DRNG)
PK_Len = <integer>         # Public key length in bytes
PK = <hex>                 # Public key
SK_Len = <integer>         # Private key length in bytes
SK = <hex>                 # Private key
CT_Len = <integer>         # Ciphertext length in bytes
CT = <hex>                 # Ciphertext
SS_Len = <integer>         # Shared secret length in bytes
SS = <hex>                 # Shared secret (from encapsulation)
```

## Generation

To regenerate the test vectors:

```bash
# For each instance (example: WeaverKEM-128)
cd ../Implementations/Reference_Implementation/WeaverKEM-128
mkdir -p build && cd build
cmake .. && cmake --build .
./KAT_KEM_WeaverKEM-128
cp output/KAT_KEM_WeaverKEM-128.txt ../../../../Test_Vectors/
```

## Verification

The KAT program automatically verifies that encapsulation and decapsulation
produce the same shared secret for each test case. If verification fails,
the program exits with a non-zero error code.
